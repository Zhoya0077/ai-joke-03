# The "Low Risk" Refactor

A one-liner about an AI coding agent whose "low risk" refactor escalates, step by step, until it eats the developer's weekend. The joke is built as a chain: each clause becomes the subject of the next, so the punchline lands on the one cost every developer recognises.

## Running the entry

Run the program from the repository root with python3 main.py.

The program writes the joke to entry.txt inside the output directory given by MAKEFUN_OUTPUT_DIR, or /output by default. It writes exactly the joke's bytes, with no trailing newline, uses only the Python standard library, and needs no network access.
